# mygame web port (WIP)
Запуск: `python3 -m http.server` в этой папке → http://localhost:8000 (игра), `viewer.html` — просмотр спрайтов/анимаций/карт.
Тесты симуляции: `node tests/sim.test.mjs`.

## Структура
- `assets/` — извлечённые ресурсы (sprites, maps, midi, wav, png_original, raw_blocks, tables)
- `js/sim.js` — чистая симуляция, портированная из `d.java`/`b.java` (коллизии, ходьба игрока, камера, анимации). Целые числа в формате 8.8, тик = 100 мс.
- `js/input.js` — счётчики клавиш как в оригинале (`ao`/`an`) + раскладка PC → клавиши телефона
- `js/game.js` — браузерная оболочка: цикл 100 мс, состояния `T`, отрисовка 240×320
- `js/engine.js` — загрузка спрайтов/карт, `main.js` — просмотрщик ассетов
- `tools/` — распаковщик .jar, конвертеры, декомпилят (CFR), `extract_tables.py` (таблицы cos и векторов направлений), `d_java_map.md` — карта `d.java`

## Сделано (checkpoint 2)
Игровой цикл 100 мс, ввод, состояния загрузка → игра, игрок идёт пешком по `city1_h`/`city2_s` (`?map=city2_s`) с коллизиями
(значение 2 = стена, как `d.t`) и камерой с упреждением (`bz`/`bA`). Клавиша **C** — слой коллизий.

## Допущения (не проверены по коду, помечено в sim.js)
- Спрайт игрока `i_00`, анимации `направление*30` (+2 при ходьбе): выведено из `b.e()`; что игрок и пешеходы используют один спрайт `bB[2]` подтверждено кодом, но что это именно `i_00` — по совпадению числа анимаций.
- Центр спрайта для камеры (`b.m()/b.n()`) считается по рамке кадра.
